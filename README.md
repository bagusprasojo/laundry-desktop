# Laundry Desktop

Aplikasi desktop laundry berbasis JavaFX + SQLite sesuai SRS.

## Stack
- Java 21
- JavaFX 21
- SQLite
- OpenPDF

## Jalankan
```bash
mvn clean javafx:run
```

## Login Default
- Username: `admin`
- Password: `admin123`

## Lokasi Data
- Database: `$HOME/.laundry-desktop/laundry.db`
- Nota PDF: `$HOME/.laundry-desktop/invoices/*.pdf`
